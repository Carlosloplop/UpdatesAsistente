# UpdatesAsistente

Repositorio público de distribución de actualizaciones de **AsistenteTasacion**.

- `latest.json` publica los canales `stable` y `beta` y admite versiones específicas por `installation_id`.
- Los paquetes de actualización se publicarán como assets de GitHub Releases.
- El código fuente no se publica aquí; permanece en el repositorio privado `Carlosloplop/AsistenteTasacion`.

Manifiesto usado por la aplicación:
`https://raw.githubusercontent.com/Carlosloplop/UpdatesAsistente/main/latest.json`
